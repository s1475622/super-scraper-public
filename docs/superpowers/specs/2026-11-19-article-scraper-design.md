# 批次文章正文擷取器設計

狀態：使用者已確認；並於檢查既有 repo 後同意沿用核心。

## 既有程式沿用

採用 Playwright 渲染、Trafilatura 正文擷取及 BeautifulSoup／markdownify 備援，建立獨立的本機文章擷取工具。保留 Markdown 作為額外匯出，JSON／CSV／TXT 以純正文為主。備援、短文、疑似登入或付費限制均留下品質提示；不以 OG 摘要冒充正文。

## 目的與已確認需求

使用者提供單一或一批文章網址，擷取網頁文章文字，供後續分析。第一版不自動探索網站首頁、分類頁或站內連結。成功的標準是輸出可閱讀、保留段落的正文，並讓每個網址的成功或失敗都能追查。

## 方案比較與採用方向

1. 純 HTTP 下載加正文擷取：安裝較簡單、速度快，但無法取得只有 JavaScript 執行後才出現的內容。
2. 每一頁都使用瀏覽器：相容較多動態頁面，但啟動、安裝與執行成本較高。
3. 預設 HTTP，提供明確選用的瀏覽器模式：兼顧批次效率和動態頁支援。

方案 3 已由使用者確認。正文擷取使用 Trafilatura，選用瀏覽器模式使用 Playwright Chromium。技術選擇由建置者提出，使用者確認後採用。

## 操作方式

第一版為已確認的本機 Python 命令列工具，附繁體中文 README、安裝步驟及範例，不架設雲端服務。圖形介面先不納入。

預期操作：

```text
super-scraper https://example.com/article --output output
super-scraper --file urls.txt --output output
super-scraper --file urls.txt --mode browser --output output
```

網址檔為 UTF-8，每行一個網址，允許空行及以 # 開頭的註解。命令列網址與檔案可合併輸入。去除完全重複的網址（忽略 fragment），保留 query，避免改變頁面含義。只接受 HTTP(S)，無效輸入產生可追查的錯誤；檔案不存在等整體輸入錯誤於發送請求前結束。

## 處理流程與模組

- 輸入層：讀取、驗證、去重網址，保留輸入順序。
- 抓取層：HTTP 下載支援重新導向、合理逾時、有限重試與回應大小上限。瀏覽器模式為選用依賴；未安裝時提供可執行的安裝指引。
- 擷取層：Trafilatura 抽取正文與 metadata，移除留言、導覽等雜訊並保留段落；支援中文及其他語言，不限定網站。不能保證所有網站均能成功。
- 批次層：逐筆執行，預設同時一筆，每個網址間隔一秒，可調整間隔、逾時及重試次數。單筆失敗不終止其他網址。
- 輸出層：結構化 JSON、方便 Excel 開啟的 UTF-8 BOM CSV，以及每篇一個 UTF-8 TXT。標準函式庫 argparse 提供命令列介面。

每個網址最多下載 10 MiB；HTTP 與瀏覽器皆檢查主要文件類型，拒絕 PDF、圖片及其他非 HTML 資料。HTTP 429 與暫時性 5xx、網路暫時性錯誤最多額外重試兩次，使用有限退避；其他 4xx 不重試。所有回應與瀏覽器資源可靠關閉。

瀏覽器模式使用乾淨的非持久 session，不讀取個人瀏覽器資料，不自動登入。等待主要文件載入及有上限的內容穩定時間，不以無限 network idle 等待作為必要條件。HTTP 預設模式不自動開啟瀏覽器；疑似空白或正文不足時提供切換模式提示。

## 輸出契約

每筆紀錄包含：輸入網址、最終網址、文章 canonical URL（若有）、標題、作者、發表日期、網站名稱、語言（若可取得）、正文、正文字符數、擷取時間（UTC ISO 8601）、模式、狀態、錯誤或品質提示。

未知 metadata 使用 null／CSV 空欄，不猜測作者、日期或語言。以 Unicode 字符數衡量長度，不把中文字符數稱為字數。預設少於 100 個非空白字符標記警告但保留正文；無正文標記失敗。這只是品質提示，無法保證已自動識別付費牆、驗證碼或截斷文章。

JSON 與 CSV 包含成功和失敗紀錄；TXT 僅為取得正文的紀錄產出，包含標題、來源網址與正文。檔名採序號及 URL 雜湊，避免 Windows 非法字元及重複標題覆寫。每次執行建立唯一子目錄，避免蓋掉既有匯出。輸出會印出實際路徑與成功、失敗、警告筆數。

程序退出碼：0 全部成功（可帶品質警告）；1 有單筆失敗但已保存其餘結果；2 整體輸入、設定、依賴或輸出錯誤。資料夾無法寫入時明確報錯。

## 範圍與限制

第一版不含全文分析、LLM API、網站搜尋、爬取整站、排程、帳號管理、代理池、付費牆或驗證碼繞過。robots.txt 以標準庫解析並快取，預設遵守明確禁止規則；無法取得時在結果留下提示，不將無法取得視為允許或禁止的證據。這是單機使用者主動執行的工具，不提供對外抓取 API。

## 驗證與交付

使用離線 HTML 樣本驗證中英文正文、段落、選單及留言排除、metadata 缺失、短文警告。使用本機 HTTP fixture 驗證重新導向、錯誤狀態、重試、非 HTML、大小限制及單筆失敗隔離。檢查 JSON、CSV、TXT 中文編碼、紀錄數及防覆寫。瀏覽器模式驗證 JavaScript 注入文章；如環境無法安裝 Chromium，清楚列出未驗證項目。

交付包含 Python 專案、可選依賴、測試、範例網址檔及繁體中文 README。依賴已安裝於專案虛擬環境，Chromium 已安裝並驗證；完整測試與實測紀錄見實作進度文件。
