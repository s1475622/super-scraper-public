# 擴大媒體、品牌與社群網站驗證

沿用已核准的單篇／批次 Python CLI。使用者要求擴大網站測試，目標為大部分網站的正文可用；先以既有擷取器做基準，保存原始 HTML，定位可修復缺陷並加入回歸測試，不導入登入憑證或付費服務。

- [x] 12 家新媒體文章、4 個品牌頁、4 個公開社群帳號入口與 1 則實際 Instagram 貼文，以及 Reuters 分類頁存取控制，分別以 HTTP／browser 實測。
- [x] 獨立對照正文段落、標題與雜訊；不把 HTTP 200、字數或 search snippet 當成完整證明。
- [x] 對可重現的程式缺陷先寫失敗測試再修復；網站登入、robots、403、地區與付費限制分開記錄。
- [x] 重跑完整測試、舊八站回歸、新樣本最終抓取；產出分母清楚的驗證報告與能力限制。

社群樣本包含四個公開帳號入口與一則源自報導者內嵌連結的 Instagram 貼文，皆保留限制結果，不宣稱支援社群貼文。Reuters 控制樣本為分類頁，不列入文章成功率。完整文章與原始 HTML 不納入 Git；來源網址與摘要結果可保存於報告。

修復正文被內嵌 article 取代、推薦／廣告／贊助污染、無限捲動多篇合併、粗體問答標題與 div 正文段落漏抓，以及 CDP 子框架關閉回呼。獨立審查提出兩項重要問題（宣告正文被擴大到兄弟文章、page.content() 後的攔截錯誤未檢查），均先重現再修復。最後完整測試 95 項通過，新樣本 13/16 個一般媒體／品牌目標通過核心區塊比對（225/225 個區塊於 TXT／Markdown 保留）。五個社群目標與 Reuters 控制受 robots 限制，兩篇媒體 403，一篇品牌活動頁仍不完整。詳見 reports/2026-11-19-expanded-sites-verification.md。
